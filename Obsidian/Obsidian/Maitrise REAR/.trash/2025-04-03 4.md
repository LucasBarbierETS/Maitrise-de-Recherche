
## Taches

#### Crées à cette date

```dataviewjs
const date = dv.current().file.name; // Récupère la date de la note
dv.taskList(dv.pages().file.tasks
  .where(t => t.created && t.created.toISODate() === date), false);
```
##### 🔄 Planifiées pour cette date
```dataviewjs
const date = dv.current().file.name; // Récupère la date de la note
dv.taskList(dv.pages().file.tasks
  .where(t => t.scheduled && t.scheduled.toISODate() === date), false);
```
