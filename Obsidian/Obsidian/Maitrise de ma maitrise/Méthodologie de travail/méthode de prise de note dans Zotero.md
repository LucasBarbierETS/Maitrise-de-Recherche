
Dans Zotero on peut annoter le texte :
-  **en le surlignant**
- **en l'encadrant**
- **en placant des notes post-it** 

La méthode employée pour la prise de note dépend du type de document et de contenu. Un article simple n'aborde pas un grand nombre de notion tandis qu'une thèse ou un libre peut aborder un très grand nombre de notion
###### Méthode 1 : Article simple

On <mark style="background: #FFB86CA6;">surligne le texte en orange</mark> pour naviguer entre entre les chapitres, parties intéressantes.

Lorsque une notion mérite d'avoir une note consacrée, on <mark style="background: #D2B3FFA6;">ajoute une note en choisissant une couleur</mark> et on nomme le concept dans les commentaire de l'annotation.

En gardant la même couleur, on surligne et encadre tous les élements jugés imporants pour être intégrés à la note.

Cette méthode est associée à commmande : 

```button
name Zotero Integration: Import 1
type command
action Zotero Integration: Import 1
```

###### Méthode 2 : Thèse ou livre

Lorsque le nombre de couleur disponible dans Zotero devient insuffisant pour séparer toutes les notions abordées, on utilise les marqueurs pour grouper les annotations. Les couleurs servent alors à séparer les annotations par nature (note, texte, image etc.)
