
Des données des annotations sont stockées dans un dossier *annotations*. On accède à ces annotations avec un point.

###### Pour du texte surligné

Les annotations de type *texte surligné* possèdent les attributs suivants :
- annotatedText : le texte surligné
- attachment 
- color : le code de la couleur
- colorCategory : la catégorie de la couleur Zotero
- comment : les commentaires associés à l'annotation
- date : 📅 27/6/2024 16:28:38
- desktopURI : le lien vers Zotero
- id : "QK88Z9MN"
- page : le numéro de page indiqué par Zotero
- pageLabel : le numéro de page indiqué par la numérotation
- source : "zotero"
- **type : "highlight"**
- x : la coordonnée horizontale
- y : la coordonnée verticale
