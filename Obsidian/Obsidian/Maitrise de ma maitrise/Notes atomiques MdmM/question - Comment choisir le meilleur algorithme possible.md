
Le type d'algoryithme dépend : 

- **de la complexité de la solutions** (nombre de variables)
- **de la régularité de la solution vis à vis de ses variables**:
	- si la solution est régulière une descente de gradient suffit
	- si la solution est irrégulière il faut une approche multistart/aléatoire
- **de la plage de valeur possible pour les variables** :
	- si la plage est petite approche robuste pour quadriller la zone
